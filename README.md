# 🏡 Travique – Airbnb Clone

Travique is a full-stack web application inspired by Airbnb that allows users to explore, create, and manage property listings.

## 🚀 Features

- 🔐 User Authentication (Signup/Login)
- 🏠 Create, edit, and delete property listings
- 📸 Image upload for listings
- 📍 Add location, price, and description
- 🔎 Browse listings with clean UI
- 📱 Responsive design

## 🛠 Tech Stack

**Frontend:**
- HTML
- CSS
- JavaScript

**Backend:**
- Node.js
- Express.js

**Database:**
- MongoDB

## 📂 Project Structure
Travique/
│── models/ # Database schemas
│── routes/ # Express routes
│── views/ # Templates (EJS or frontend)
│── public/ # Static files (CSS, JS)
│── app.js # Main server file
